# 마이캐 파츠 노트 ★

아이카츠! 앙코르 마이캐릭터 파츠를 기록하고 정리하는 팬 제작 비공식 웹앱입니다.
설치 없이 브라우저에서 쓰고, 홈 화면에 추가하면 앱처럼 열립니다. 오프라인에서도 동작해요.

## 기능
- 파츠 정보: 사진, 파츠 이름, 일본어 이름, 몇 탄 파츠인지, 획득 경로(기본/이벤트/스탬프/랭크 달성 + 상세), 카테고리, 메모
- 카드 바인더처럼 사진 중심으로 보여 주고, 보유는 금색 테두리, 원해요는 테마 컬러, 미보유는 반투명으로 표시
- 스탬프/랭크 달성은 몇 번째인지 기록(랭크는 큐트·쿨·섹시·팝 타입 선택)하고, 먼저 얻을 수 있는 순서(탄 → 획득 경로 → 몇 번째)로 정렬
- 정렬: 탄 → 획득 경로(기본 → 이벤트 → 스탬프 → 랭크) → 랭크는 큐트 전체 → 쿨 전체 → 섹시 전체 → 팝 전체, 각 타입 안에서는 번호 순
- 페이스: 카테고리를 페이스로 고르면 큐트·쿨·섹시·팝 타입을 고를 수 있고, 파츠 탭에서 큐트 → 쿨 → 섹시 → 팝 순서로 정렬
- 탄별 탭: 탄을 고르고 이벤트/스탬프/큐트·쿨·섹시·팝 랭크별로, 얻는 순서대로 파츠를 트랙처럼 확인
- 테마 컬러 7가지 + 직접 고르기
- 기본 카테고리: 페이스, 보이스, 헤어 파츠, 헤어 컬러, 아이 컬러, 메이크업, 원 포인트, 헤어 데코, 기타
- 이미지: 파츠마다 이미지 1장. [이미지로 한 번에 등록]으로 여러 장을 한꺼번에 올리면 파일 이름이 파츠 이름(또는 일본어 이름)이 되고, 이름이 같은 기존 파츠가 있으면 그 파츠에 이미지를 연결해요. PC에서는 화면에 끌어다 놓아도 돼요.
- 상태 도장: 보유 ↔ 미보유 (타일 왼쪽 위 도장을 누를 때마다 바뀜)
- 파츠를 누르면 정보 화면: 사진, 한국어·일본어 이름, 탄, 획득 경로, 메모를 보고 보유/미보유와 하트를 바로 바꿀 수 있어요. [정보 수정]을 누르면 편집 화면이 열려요
- 원해요: 하트로 표시. 하트 파츠는 사진 오른쪽 위에 작은 하트가 뜨고, 미보유 목록에도 그대로 보여요
- 탭: 파츠 / 탄별 / 조합 / 정보 / 설정
- 정보 탭: 업데이트 소식, 게임 소식을 올리고(제목, 날짜, 내용, 링크, 고정) parts-data.json에 담아 모두에게 공유. 새 소식이 오면 탭에 점 표시
- 검색, 상태/카테고리/탄/획득 경로 필터, 카테고리별 보유율
- 조합: 카테고리별로 파츠를 골라 마이캐 조합 저장
- 더보기 메뉴: 이미지 한 번에 등록, 백업 파일 저장하기/불러오기, 목록 붙여 넣기/복사하기, 최신 버전 다시 받기
- 백업 코드(JSON, 이미지 포함 선택) 복사, 파일 저장, 불러오기(합치기/덮어쓰기)
- 카테고리, 획득 경로 직접 추가/삭제, 밝게/어둡게 화면

## GitHub Pages로 배포하기
1. GitHub에서 새 저장소를 만듭니다 (예: `aikatsu-parts`, Public).
2. 이 폴더의 파일을 모두 업로드합니다. (`Add file` → `Upload files`, `icons` 폴더 포함)
3. 저장소 `Settings` → `Pages` → Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 두고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/aikatsu-parts/` 주소가 생깁니다.

## 아티팩트에서 정리한 파츠를 사이트에 넣기
1. Claude 아티팩트(마이캐 파츠 노트)에서 설정 탭 → "이미지도 함께 백업"을 켜고 → [백업 코드 복사]를 누릅니다.
2. GitHub 저장소에서 `Add file` → `Create new file`을 누르고, 파일 이름을 `parts-data.json`으로 적습니다.
3. 복사한 코드를 그대로 붙여넣고 `Commit changes`를 누릅니다.
4. 1~2분 뒤 사이트를 열면 파츠, 사진, 카테고리, 획득 경로, 테마 컬러가 그대로 들어가 있어요.

- 처음 여는 기기에서는 이 목록이 통째로 들어가고(보유 상태 포함), 이미 쓰던 기기에서는 새 파츠만 추가되고 바뀐 정보(이름, 탄, 획득 경로 등)가 반영돼요. 각자 체크한 보유 상태와 메모는 지켜집니다.
- 파츠를 더 정리했다면 같은 방법으로 `parts-data.json` 내용을 새 백업 코드로 바꿔 커밋하면 돼요. 이때는 `sw.js` 버전을 올리지 않아도 됩니다.
- 다른 사람에게 링크를 공유했다면, 그 사람은 설정 탭의 [보유 상태만 모두 미보유로]로 자기 기록을 새로 시작할 수 있어요.
- 백업 코드가 너무 길어 붙여넣기가 잘 안 되면, 이미지를 빼고 백업하거나 사이트에서 [파일 불러오기] 후 [파일로 저장]한 파일을 업로드해도 돼요.

## 소식 올리기
1. 아티팩트(또는 사이트)의 정보 탭에서 [+ 소식 쓰기]로 글을 올려요.
2. 더보기 → [백업 파일 저장하기]로 받은 파일을 `parts-data.json`으로 이름을 바꿔 저장소에 올려요.
3. 사이트를 여는 사람 모두에게 새 소식이 들어가고, 정보 탭에 점이 표시돼요. 파일에서 지운 소식은 다른 기기에서도 사라져요.

## 폰에 앱처럼 설치하기
- 안드로이드(Chrome): 주소를 열고 메뉴 ⋮ → `홈 화면에 추가` 또는 `앱 설치`
- 아이폰(Safari): 공유 버튼 → `홈 화면에 추가`

## 아이폰·맥 파일 이름 문제
아이폰이나 맥에서 만든 파일 이름은 한글·일본어가 자모로 쪼개진 형태(NFD)로 저장돼서, 겉보기엔 같은 이름이어도 글꼴이 달라 보이고 다른 글자로 취급돼요. 앱이 모든 이름을 표준형(NFC)으로 맞춰서 비교하고, 이 문제로 생긴 같은 이름 파츠는 업데이트 후 처음 열 때 한 번 자동으로 합쳐요.

## 최신 버전이 안 보일 때
더보기 → [최신 버전 다시 받기]를 누르면 저장된 화면을 지우고 새로 받아요. `parts-data.json`도 다시 확인해 반영하고, 내 보유 기록은 그대로 남아요.

## 업데이트할 때
`index.html`을 고친 뒤 `sw.js` 맨 위의 `CACHE = 'parts-note-v14'` 숫자를 올려 주세요.
그래야 이미 설치한 사람에게도 새 버전이 확실히 반영됩니다.

## 데이터 저장 방식
파츠 정보는 localStorage, 이미지는 IndexedDB에 각자 기기의 브라우저에만 저장되고 서버로 보내지 않습니다.
브라우저 데이터를 지우면 함께 사라지니 설정 탭에서 가끔 백업해 두세요.
Claude 아티팩트 버전과 GitHub 버전은 저장 공간이 서로 달라서, 옮길 때는 백업 코드를 복사해 붙여넣으면 됩니다.

## 참고
게임 이미지, 공식 파츠 목록 등 저작물은 포함하지 않습니다. 파츠 정보와 이미지는 사용자가 직접 올리며, 올린 이미지는 360px 크기로 줄여 자기 기기에만 저장돼요.
